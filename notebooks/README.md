This project is organized into three notebooks:

1. **01_initial_inspection.ipynb**
   - Understand raw data structure and quality
   - Identify missing values and anomalies
   - Validate business-critical fields

2. **02_data_cleaning.ipynb**
   - Clean and standardize the dataset
   - Create revenue and return indicators
   - Prepare data for SQL ingestion

3. **03_eda.ipynb**
   - Explore sales, customer, and product trends
   - Identify seasonality and revenue concentration
   - Generate insights before dashboarding

Each notebook builds on the previous one and supports the final
SQL views and Tableau dashboards.
